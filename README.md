# TOTK Luma

A personal-use, Mac-first project to play a legally owned copy of *The Legend of Zelda: Tears of
the Kingdom* through an open-source Switch emulator, with three goals: stable high frame rates,
genuine HDR on Apple displays and an HDR TV, and excellent DualSense support.

This repository contains **specifications and a visual-scope demo only**. It contains no
emulator binaries and no Nintendo content of any kind. See [AGENTS.md](AGENTS.md) for the rules.
